# Jewellery Factory — Digital Transformation Initiative

EXECUTIVE SUMMARY
═════════════════
This proposal outlines the deployment of AI Agents across 5 core departments of
the jewellery factory to automate repetitive workflows, reduce errors, cut costs,
and accelerate decision-making. The system is built on a CrewAI + FastAPI +
PostgreSQL stack and integrates with existing ERP, design tools, and HR systems.

Estimated Total Investment  : ₹ 29,00,000 – ₹ 47,00,000 (Year 1)
Projected Annual Savings    : ₹ 34,00,000 – ₹ 56,50,000
Expected ROI (Year 2+)      : 140% – 220%
Payback Period              : 8 – 14 months
Cost-Optimized Pilot Option : ₹ 3,50,000 – ₹ 7,00,000 for NPD-first rollout

DEPARTMENT 1 — NEW PRODUCT DEVELOPMENT (NPD)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CURRENT PAIN POINTS
───────────────────
• Trend research is done manually (browsing Pinterest, trade magazines, competitor sites)
• New product briefs take 3–5 days to prepare
• BOM (Bill of Materials) is created manually in Excel — prone to errors
• No structured way to track which designs sold well vs. which failed
• Competitive benchmarking is ad hoc

AI AGENTS PROPOSED
──────────────────

Agent 1.1 — Trend Research Agent
  What it does:
  • Monitors fashion trend feeds, social media, Google Trends, trade portals
  • Summarizes top trending jewellery styles, colors, stones every week
  • Tags trends by occasion (bridal, daily wear, festive) and customer segment
  • Generates a weekly trend report PDF automatically

  Tools Used:
  • Web scraping + Tavily Search API
  • GPT-4o for summarization
  • Scheduled cron trigger (every Monday 8AM)

  Inputs  : Trend sources list, target segments, competitor URLs
  Outputs : Weekly trend brief, design inspiration keywords, top 10 trending SKUs

Agent 1.2 — Product Brief Generator Agent
  What it does:
  • Takes a simple design idea (voice note / text) and generates a full product brief
  • Auto-fills: product name, category, target customer, metal spec, stone suggestion,
    occasion fit, estimated price range, production complexity rating
  • Stores brief in the product database for designer review

  Tools Used:
  • GPT-4o (LLM reasoning)
  • Product database (PostgreSQL)
  • Metal rate API (for price estimate)

  Inputs  : Designer's rough idea (text/voice)
  Outputs : Structured product brief with specs, pricing estimate, priority score

Agent 1.3 — BOM (Bill of Materials) Automation Agent
  What it does:
  • Auto-generates BOM from approved product spec
  • Lists: metal type, purity, weight, stones (type/size/quantity), findings, packaging
  • Validates against inventory — flags missing materials before production starts
  • Calculates material cost, making cost, and margin estimate

  Tools Used:
  • PostgreSQL (product + inventory tables)
  • Pricing calculator tool
  • Inventory check tool

  Inputs  : Approved product spec sheet
  Outputs : Complete BOM with cost breakdown, inventory gap report

Agent 1.4 — Post-Launch Performance Agent
  What it does:
  • Tracks sales velocity of new products for 90 days post-launch
  • Identifies slow-moving designs and recommends: discount / discontinue / redesign
  • Flags best-sellers for capacity increase recommendation

  Tools Used:
  • Sales database queries
  • GPT-4o analysis

  Inputs  : Product sales data (daily)
  Outputs : 90-day performance report, action recommendations

Agent 1.5 — Sample Development Workflow Agent
  What it does:
  • Digitizes the full sample development SOP from design approval to final QC
  • Handles both customer-owned designs and in-house designs separately
  • Tracks sample ownership rules so customer-owned designs are not reused without approval
  • Creates sample IDs and monitors stage-wise progress:
    Design → Master Casting → Master Creation → Polishing → Stone Setting → Final QC
  • Captures responsibility, start date, expected completion, current stage, and status
  • Raises alerts for delayed samples, blocked stages, labour shortages, and material shortages

  Tools Used:
  • PostgreSQL sample tracking tables
  • Workflow engine / stage transition rules
  • Notification tool for Design, Production, Procurement, and QC teams

  Inputs  : Approved design, sample type, required material, required stones, target date
  Outputs : Sample tracking record, stage status, delay alerts, approval/rejection history

Agent 1.6 — NPD Resource & KPI Dashboard Agent
  What it does:
  • Builds real-time visibility across the NPD sample pipeline
  • Tracks sample pipeline by customer-specific vs. in-house designs
  • Monitors labour availability for master creation, polishing, stone setting, and QC
  • Tracks raw material stock: opening stock, used quantity, balance, reorder level
  • Tracks stone inventory: type, size, quality, available quantity, required quantity, order status
  • Calculates KPIs automatically: cycle time, rejection rate, rework %, stage-wise delay,
    worker productivity, labour utilization, idle time, and supplier fulfillment rate
  • Generates management dashboard summary every day

  Tools Used:
  • PostgreSQL analytics views
  • FastAPI dashboard endpoints
  • Excel/PDF report generator
  • Optional React/Streamlit dashboard

  Inputs  : Sample tracking data, inventory data, labour data, QC results, procurement status
  Outputs : NPD dashboard, KPI reports, exception alerts, productivity summary

SOP AUTOMATION COVERAGE — SAMPLE DEVELOPMENT
────────────────────────────────────────────
  Objective:
  • Establish a standardized digital process for new jewellery sample development
  • Improve quality, cycle time, resource utilization, and management visibility

  Scope:
  • Customer-specific jewellery designs
  • In-house developed jewellery designs
  • Departments involved: Design, Production, Procurement, QC, Management

  Sample Types:
  • Customer-Owned Design: ownership remains with customer and reuse requires permission
  • In-House Design: developed internally and reusable across customers/collections

  Digital Process Flow:
  • Design Approval
  • Master Casting
  • Master Creation / Hand Finishing
  • Polishing
  • Stone Setting, if required
  • Final Quality Check

  Stage-Level Automation:
  • Design Stage: capture design source, feasibility check, approval status
  • Master Casting: assign casting team, record mould/casting status, output rough master
  • Master Creation: assign skilled artisan, track detailing accuracy and completion
  • Polishing: assign polisher, capture finish quality and completion time
  • Stone Setting: validate stone availability, assign stone setter, record setting completion
  • Final QC: inspect design accuracy, finish, stone alignment, and structural quality

  Digital Templates to be Automated:
  • Sample Tracking Sheet: Sample ID, type, design name, stage, start date, expected completion, status
  • Stage Monitoring Template: stage-wise pending, in-progress, and completed samples
  • Stone Inventory Template: stone type, size, quality, available quantity, required quantity, order status
  • Raw Material Tracking Template: opening stock, used, balance, reorder level, status
  • Labour Availability Sheet: required labour, available labour, shortage, remarks
  • Productivity Tracking Sheet: employee, stage, units completed, time taken, productivity rate

  Dashboard Requirements:
  • Sample pipeline: customer-owned vs. in-house
  • Stage-wise sample progress
  • Stone inventory and procurement status
  • Raw material stock and consumption
  • Labour availability and allocation
  • Productivity metrics and bottleneck alerts

  KPIs to be Tracked:
  • Production: total samples in pipeline, cycle time, stage-wise delay %, on-time delivery rate
  • Quality: rejection rate %, rework %, QC pass rate
  • Inventory: raw material availability %, stock turnover, stock-out frequency, stone availability vs. requirement
  • Labour: productivity per worker, labour utilization %, idle time %, stage efficiency
  • Procurement: stone procurement lead time, supplier fulfillment rate %, cost variance

  Responsibility Matrix:
  • Design Team: design creation, feasibility validation, approval
  • Production Team: sample development through casting, master creation, polishing, and setting
  • Procurement Team: raw material and stone availability
  • QC Team: sample inspection and approval/rejection
  • Management: monitoring, exception handling, and decision-making

NPD COST-OPTIMIZED AI IMPLEMENTATION APPROACH
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

OBJECTIVE
─────────
This section defines a practical, low-cost AI rollout for the jewellery New
Product Development process. The aim is to start with free/open-source AI tools,
avoid heavy recurring API costs, and deploy advanced automation only after value
is proven.

1. DESIGN STAGE — HIGHEST IMPACT AREA
──────────────────────────────────────
  Where AI Helps:
  • Generate new jewellery design concepts
  • Convert sketches into 3D design ideas
  • Create quick customer design variations for proposal approval

  AI Use Cases:
  • Design suggestion based on trending styles and pattern variations
  • Auto CAD concept generation for early-stage visualization
  • Image-to-design conversion from rough sketch or reference image

  Low-Cost AI Models / Tools:
  • Stable Diffusion: open-source jewellery image generation, free if local
  • DALL-E API: pay-per-use option for selected premium sample concepts
  • Blender + AI plugins: free 3D modelling support
  • Runway ML: affordable visual AI tools for concept exploration

  Recommendation:
  • Use Stable Diffusion locally for most design concepts to reduce recurring cost
  • Use DALL-E only for high-priority customer presentations or premium concepts

2. MASTER CREATION / CASTING STAGE
───────────────────────────────────
  Where AI Helps:
  • Predict casting defects
  • Suggest ideal material mix using past production data
  • Reduce rework and rejected master samples

  AI Use Cases:
  • Defect detection using image analysis
  • Pattern recognition from historical defect images
  • Casting condition recommendations based on previous successful batches

  Low-Cost AI Models / Tools:
  • OpenCV: free image processing
  • TensorFlow Lite / PyTorch Mobile: lightweight local ML models
  • Open-source anomaly detection models

  Recommendation:
  • Start with OpenCV + a basic ML model running on a local PC
  • Train models gradually using factory defect images

3. POLISHING STAGE
──────────────────
  Where AI Helps:
  • Check surface finishing quality
  • Detect scratches, uneven polish, dull patches, and visible marks

  AI Use Cases:
  • Computer vision inspection system for polishing quality
  • Pass/fail support for operator and QC team

  Low-Cost AI Models / Tools:
  • OpenCV + camera setup
  • YOLOv5 / YOLOv8 for real-time defect detection

  Recommendation:
  • Deploy a small AI model with a fixed camera station
  • Keep it as an assistant to the polisher/QC team in Phase 1

4. STONE SETTING STAGE
──────────────────────
  Where AI Helps:
  • Verify correct stone placement
  • Check alignment, missing stones, wrong stone size, and setting defects

  AI Use Cases:
  • Image-based inspection
  • Pattern matching against approved design reference
  • Missing or misaligned stone detection

  Low-Cost AI Models / Tools:
  • YOLO object detection, open source
  • Edge AI models, optional Raspberry Pi deployment

  Recommendation:
  • Train YOLO using internal product images for stone-setting inspection
  • Start with critical products such as high-value rings, pendants, and bridal sets

5. FINAL QUALITY CHECK (QC)
───────────────────────────
  Where AI Helps:
  • Automated QC inspection support
  • Reduce manual checking errors
  • Improve consistency in pass/fail decisions

  AI Use Cases:
  • Defect classification
  • Pass/fail recommendation
  • Standard compliance checking against design and finish criteria

  Low-Cost AI Models / Tools:
  • Custom CNN model using PyTorch or TensorFlow
  • Rule-based QC checks using OpenCV
  • Google Vertex AI AutoML for limited experiments, if needed

  Recommendation:
  • Start with rule-based checks + simple ML model instead of full AI automation
  • Keep final approval with QC team until model accuracy is proven

6. INVENTORY & MATERIAL PLANNING — VERY HIGH ROI
─────────────────────────────────────────────────
  Where AI Helps:
  • Predict stone demand
  • Optimize gold, silver, copper, and stone usage
  • Reduce stock-outs and urgent procurement

  AI Use Cases:
  • Demand forecasting
  • Reorder alerts
  • Consumption prediction by product type, sample type, and season

  Low-Cost AI Models / Tools:
  • Excel + Python ML models such as ARIMA and regression
  • Prophet forecasting model, free/open source
  • Power BI with AI visuals

  Recommendation:
  • Use Prophet + Excel/Power BI for a cost-effective forecasting layer
  • Start with stone inventory and high-value raw material categories

7. LABOUR PRODUCTIVITY & PLANNING
─────────────────────────────────
  Where AI Helps:
  • Measure worker efficiency
  • Allocate labour intelligently across NPD stages
  • Predict time required per stage

  AI Use Cases:
  • Productivity analytics
  • Workload balancing
  • Stage-wise time prediction
  • Idle time and labour utilization tracking

  Low-Cost AI Models / Tools:
  • Python regression and clustering models
  • Power BI AI insights
  • Existing production tracking database

  Recommendation:
  • No heavy AI is needed initially
  • Use data analytics + simple ML for immediate visibility and planning support

8. DASHBOARD — CENTRAL AI INTEGRATION LAYER
────────────────────────────────────────────
  Where AI Helps:
  • Provide real-time operational visibility
  • Convert raw tracking data into alerts and decisions
  • Support daily management review

  AI Features:
  • Delay prediction
  • Bottleneck detection
  • Smart notifications for low stock, delayed samples, labour shortage, and QC failure

  Low-Cost Tools:
  • Power BI as the best low-cost business dashboard option
  • Streamlit as a free Python-based dashboard option
  • FastAPI + PostgreSQL backend for live data

  Recommendation:
  • Start with Power BI + Python backend if management needs polished dashboards
  • Use Streamlit if the priority is fast, zero-license-cost internal deployment

COST OPTIMIZATION STRATEGY
──────────────────────────
  Phase 1 — Low / Zero Cost Immediate Start:
  • Excel + Power BI dashboard
  • Stable Diffusion for design generation
  • OpenCV for QC checks
  • Basic Python models for forecasting and productivity analysis
  • Estimated Cost: ₹ 3,50,000 – ₹ 7,00,000 including setup, camera station, and training

  Phase 2 — Moderate Investment:
  • Train YOLO models for polishing, stone setting, and final QC
  • Deploy forecasting models for materials and stones
  • Add automation pipelines and scheduled alerts
  • Estimated Additional Cost: ₹ 4,00,000 – ₹ 8,00,000

  Phase 3 — Advanced AI, Optional:
  • IoT + AI cameras at each production stage
  • Auto design-to-production data pipeline
  • Edge AI deployment for continuous inspection
  • Estimated Additional Cost: ₹ 8,00,000 – ₹ 18,00,000 depending on camera/GPU hardware

FINAL COST-OPTIMIZED RECOMMENDATION
────────────────────────────────────
  Start AI in 3 priority areas first:
  • Design Generation: fastest visible ROI and improves customer proposal speed
  • QC Automation: reduces rejection, rework, and manual inspection inconsistency
  • Inventory Forecasting: reduces stock-outs and improves material planning

  Expansion Path:
  • After 60–90 days of pilot results, expand to polishing inspection, stone-setting

  • Use paid APIs only where they clearly improve client-facing output or reduce
    measurable operational cost.

DEPARTMENT 2 — PRODUCTION PLANNING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CURRENT PAIN POINTS
───────────────────
• Production schedules are made manually in Excel — updated inconsistently
• Rush orders disrupt existing schedules with no systematic re-prioritization
• Craftsman skills are not tracked — wrong person assigned to specialized tasks
• Material shortage discovered only at the production stage (not before)
• No visibility on which stage is the bottleneck

AI AGENTS PROPOSED
──────────────────

Agent 2.1 — Daily Production Planning Agent
  What it does:
  • Every morning, reads all pending + confirmed orders
  • Creates production jobs, assigns craftsmen based on skill + availability
  • Builds an optimized daily schedule (Gantt-style)
  • Flags jobs at risk of missing delivery date
  • Sends plan summary to floor supervisors via WhatsApp/Email

  Tools Used:
  • PostgreSQL (orders, craftsmen, workflow templates)
  • Scheduling algorithm (constraint-based)
  • Notification tool (WhatsApp Business API / SMTP)

  Inputs  : Orders list, craftsman availability, workflow templates
  Outputs : Daily production schedule, assignment list, risk alerts

Agent 2.2 — Material Requirement Planning (MRP) Agent
  What it does:
  • Before production starts, calculates exact material needed per job
  • Checks live inventory — raises purchase requests for shortfalls
  • Tracks issued vs. returned vs. wasted material per job
  • Generates wastage reports by craftsman and product type

  Tools Used:
  • Inventory database
  • BOM data from NPD agent
  • Supplier contact database

  Inputs  : Confirmed production jobs
  Outputs : Material issue list, purchase requisitions, wastage dashboard

Agent 2.3 — Bottleneck Detection & Re-scheduling Agent
  What it does:
  • Monitors production task completion in real time
  • Detects delays, craftsman absences, machine breakdowns
  • Automatically re-schedules impacted jobs
  • Recommends outsourcing for overflow work

  Tools Used:
  • Real-time task status polling (PostgreSQL)
  • GPT-4o for re-scheduling reasoning

  Inputs  : Live task status updates
  Outputs : Revised schedule, alerts, escalation notifications

Agent 2.4 — Production Reporting Agent
  What it does:
  • Generates daily production summary (completed / in-progress / delayed)
  • Weekly output report: units produced, on-time %, wastage %
  • Craftsman productivity report

  Tools Used:
  • Database aggregation queries
  • PDF/Excel report generation (reportlab / openpyxl)

  Inputs  : Production task data
  Outputs : Daily/weekly automated reports

DEPARTMENT 3 — FINANCE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CURRENT PAIN POINTS
───────────────────
• Invoices are typed manually — slow and error-prone
• Gold rate fluctuates daily but pricing is updated infrequently
• GST filing preparation takes 2–3 days every month
• Profitability per order/product is not tracked in real time
• Payment follow-ups are done manually via phone calls

AI AGENTS PROPOSED
──────────────────

Agent 3.1 — Dynamic Pricing Agent
  What it does:
  • Fetches live gold/silver rates every morning (GoldAPI / MCX feed)
  • Recalculates product prices across catalogue automatically
  • Updates price list — marks products where margin has dropped below threshold
  • Sends pricing update summary to management

  Tools Used:
  • GoldAPI.io / MCX live feed
  • Product pricing tables (PostgreSQL)
  • Email/WhatsApp notification

  Inputs  : Live metal rates, product BOM data
  Outputs : Updated price list, margin alert report

Agent 3.2 — Invoice Automation Agent
  What it does:
  • Auto-generates GST-compliant invoices on order completion
  • Applies correct HSN codes for jewellery (7113, 7114, 7117)
  • Calculates: metal value + making charges + stone value + GST (3%)
  • Stores invoice in PDF + pushes to accounting system (Tally/Zoho)

  Tools Used:
  • Order + pricing database
  • ReportLab (PDF generation)
  • Tally API / Zoho Books API (optional)

  Inputs  : Completed order data
  Outputs : GST invoice PDF, accounting entry

Agent 3.3 — Profitability Tracker Agent
  What it does:
  • Calculates actual profit per order: selling price − (material cost + labor + overhead)
  • Tracks margin trends by product category, customer type, collection
  • Flags loss-making orders and identifies root cause (material spike, excess labor)
  • Monthly P&L summary per product line

  Tools Used:
  • Cost + sales database
  • GPT-4o for root-cause narrative

  Inputs  : Order costs, labor hours, material usage
  Outputs : Per-order P&L, monthly summary report

Agent 3.4 — Payment Follow-up Agent
  What it does:
  • Monitors outstanding receivables (advance paid vs. balance due)
  • Sends automated payment reminders at D+7, D+15, D+30 via WhatsApp/SMS
  • Escalates overdue accounts to accounts manager
  • Tracks payment receipt and closes dues automatically

  Tools Used:
  • Customer + order database
  • WhatsApp Business API / Twilio SMS
  • APScheduler (cron triggers)

  Inputs  : Order payment status
  Outputs : Automated reminders, overdue report

Agent 3.5 — GST Filing Preparation Agent
  What it does:
  • Aggregates all sales invoices, purchase bills, and input tax credit for the month
  • Prepares GSTR-1 and GSTR-3B summary in Excel format
  • Flags mismatches between purchase GST and sales GST
  • Exports data in format compatible with ClearTax / GST portal

  Tools Used:
  • Invoice + purchase database
  • openpyxl (Excel generation)
  • ClearTax API (optional)

  Inputs  : Monthly transaction data
